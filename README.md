# ⚡ Neurozhirik ⚡

---

### Народные умельцы превратили дух Жириновского в сервитора и заставили его веселить людей в группах в Telegram.

## 🎯 Как пообщаться с Жириком?

Чтобы начать общение с нейрожириком:
1. **Добавьте бота** [@Neurozhirobot](https://t.me/Neurozhirobot) в свою группу
2. **Ответьте** на любое сообщение в группе
3. **Начните сообщение** с: "Жирик", "Жириновский", "ввж", "володя", "жириновский" или упомяните @Neurozhirobot

**Бот умеет:**
- ✅ Отвечать в стиле Жириновского (агрессивно, с сарказмом)
- ✅ Анализировать фотографии и описывать их
- ✅ Работать параллельно с несколькими пользователями
- ✅ Быстро генерировать ответы (до 150 слов)

## 🚀 Быстрый запуск (Docker)

### 1. Получите ключи API
```
# Перейдите на https://my.telegram.org
# Получите API_ID и API_HASH

# Создайте бота через @BotFather
# Получите BOT_TOKEN

# Зайдите на https://ollama.com/
# Создайте аккаунт и API-ключ
```

### 2. Настройка окружения
```bash
# Клонируйте репозиторий
git clone https://github.com/danyayok/neurozhirik
cd neurozhirik

# Создайте .env файл
nano .env
```

```env
API_ID=ваш_api_id
API_HASH=ваш_api_hash
BOT_TOKEN=ваш_bot_token
OLLAMA_HOST=https://ollama.com
OLLAMA_TOKEN="ваш_ollama_токен"
```

### 3. Запуск
```bash
# Сборка и запуск
docker-compose build
docker-compose up -d

# Просмотр логов
docker-compose logs -f
```

## 🔄 Обновление бота

```bash
# Всего 2 команды для обновления!
git pull
docker-compose up --build -d
```

## 🛠 Ручная установка (без Docker)

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск
python main.py
```

## 📊 Команды бота

- `/start` - приветственное сообщение
- `/status` - статус бота и активные запросы  
- `/ptichko` - получить тестовое изображение
- `/test_image` - протестировать анализ изображений

## ⚠️ Важные моменты

- Бот отвечает **ТОЛЬКО в группах**
- Нужно **ответить на сообщение** и упомянуть бота
- Работает с **фотографиями** - анализирует и описывает их
- **Параллельная обработка** - может отвечать сразу нескольким пользователям
- **Ограничение длины** - ответы до 150 слов

## 🐛 Решение проблем

Если бот не отвечает:
1. Проверьте, что бот добавлен в группу
2. Убедитесь, что есть права на отправку сообщений
3. Проверьте формат сообщения: "ответ на сообщение + триггерное слово"
4. Посмотрите логи: `docker-compose logs -f`
