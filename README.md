# ⚡ Neurozhirik ⚡

### Народные умельцы превратили дух Жириновского в сервитора и заставили его веселить людей в группах, в телеграмме. 

## Как пообщаться с Жириком?

Чтобы начать общение с нейрожириком, вы можете добавить бота (https://t.me/Neurozhirobot) в свою группу и пообщаться, либо хостить самому.
Нейрожирик будет отвечать ТОЛЬКО если вы ответите на сообщение и НАПИШЕТЕ В НАЧАЛЕ: "Жирик", "Жириновский", "ввж"... Умеет описывать фотографии, можно поржать с него минут 10 и бросить.

## Как запустить бота?

1. Переходите на https://my.telegram.org/auth
Вводите номер, код и копируете API_ID и API_HASH.
В https://t.me/BotFather создаёте бота и копируете оттуда BOT_TOKEN 
2. создаёте .env файл в корне проекта:
```python
API_ID=ваш_api_id
API_HASH=ваш_api_hash
BOT_TOKEN=ваш_bot_token
```
3. Произведите деплой
